# 第一次用 codex-security 演练 | First codex-security drill: hygiene, scan, patch

在一个不重要的真仓库上把关键动作走一遍，先立纪律，再开扫：

1. **先查环境门槛**：确认 Node.js 在 22.13.0 以上（22.x 线）或 24.x 或 26.x，Python 在 3.10 以上（3.10 再补装 `tomli`）。不在这几条线上的先升级。
2. **扫前清凭据**：CLI 以你本人的系统权限运行、不会停下来问批准。开扫前先把和这个仓库无关的凭据移出当前 shell 的环境变量，只留扫描进程要用的那一把。
3. **装与登录**：`npm install --global @openai/codex-security`，然后 `cs login`；短名冲突就改用全名 `codex-security`，或全程用 `npx @openai/codex-security`。
4. **小范围首扫**：先别整仓，先挑一个路径：`cs scan . --path src`。扫完打开终端给出的 REPORT 路径，先看报告里的排除项与覆盖边界，再看发现本身。
5. **验一条、补一条**：挑一条候选发现，让它验证是否真能触发；验证成立的再让它生成补丁。用 `cs scans show` 找回这次扫描，确认报告与产物都存在了仓库外的私密位置，没有顺手提交进代码仓。
6. **算一回账**：记下这次小扫的实际用量与费用，再决定要不要放大到整仓或 `--mode deep`——官方示例的 5 美元是估算上限、进行中的请求可能超限，先有小样本再设 CI 的上限。
